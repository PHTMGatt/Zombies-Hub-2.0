# Der Eisendrache: what the egg is, what shape follows

Source: [codzombiesguides.com Der Eisendrache](https://www.codzombiesguides.com/main-quests/black-ops-3/der-eisendrache/) (one source). CHARLIE · Sonnet, 2026-11-17.

## The mechanic
**Four bow quests** (each a mini egg), then a shared back half:
1. Feed three dragons (eight single kills each in our data; one source says six), claim the Wrath of the Ancients.
2. **Upgrade to a bow:** Storm (weathercock, bonfires, wall-run panels, urns), Fire (rocket pad, three circles, four Wrath shots), Wolf (four paintings in story order, positions random per game; wolf skull; digsites), Void (six skulls, six crawlers, three crests spoken, enter the symbols in order). Then the Anti-Gravity squares and the altar.
3. **Wisps:** four per cycle, eight possible spots, never the same spot twice in a cycle (a **location hunt**).
4. The past: everyone on the purple pad, 500 points; soul canister, fuses, **safe code (random per game)**.
5. Boss: build the Ragnarok DG-4s (Panzer drop round 12, Death Ray part, Rocket Test Site part), stun the boss, damage with XM-53 or Ray Gun.
Each player upgrades a bow: **solo needs one, local/unranked needs all four**.

## Shape that follows
- **Main guide:** dragons → bow → wisps → past → boss.
- **Tabs the egg demands:** **Bows**, one page per bow (the bows are the egg); **Wisps** (the eight-spot hunt); **Parts**; **Boss**. All built.
- **Evidence needed:** the eight wisp spots, each with a picture + landmark. The four painting positions are random, so that page must be a "match what you see" table, not positions. See `docs/MISSING-MEDIA.md`.
